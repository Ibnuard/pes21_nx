## v71r2 loose-CPK packaging correction

The first v71 skin package inherited the physique baseline manifest, including
the pre-cinematic dt220 row (31,919,921 bytes). Installed walkout/trophy packages
use the preserved 34,215,936-byte dt220. Native startup correctly refused that
mixed installation before entering the game. This was a packaging error, not
a failed skin patch or a reason to weaken startup validation.

Compose skin updates into the current cinematic manifest with
`tools/compose_loose_cpk.py`, preserving its other 23 entries. Verify every CPK
and the dummy OBB through an explicitly ordered overlay of package and baseline
paths; no OBB or unchanged payload needs copying. A corrupt higher-priority file
must fail rather than silently selecting a lower-priority matching file.

The r2 delivery retains the exact v71 NRO, FootballNX.assets and skin CPK. It
also carries the existing pinned cinematic CPK and prop PAK and refreshes the
marker with the composed manifest hash. Native marker/cinematic guards remain
unchanged. The actual C validator reproduces the old dt220 failure and accepts
the composed set; the old marker is rejected against the new manifest. Tests
also exercise this mismatch with small synthetic archives. Host validation is
not evidence that the previously unresolved trophy animation now plays.

The corrected ready-copy directory and ZIP are
`local-debug/review-v71/FootballNX-v71r2-LOOSE-FIX-SIAP-COPY`. Its seven runtime
files form the supported update set. The first four-file v71 package is
superseded. New realface packaging must use the r2 manifest and marker together
with the pinned gameplay/assets payloads.
