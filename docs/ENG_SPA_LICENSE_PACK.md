# English and Spanish Team Licensing

For native crest integration, stable packaging and hardware acceptance checks,
see [Stable migration guide](KITS_LOGOS_STABLE_MIGRATION.md).

This lane stages official 2025/26 English and Spanish club names plus a kit
source inventory. It is intentionally separate from Game Plan, Inter Miami,
the badge atlas, the Makefile, and NRO/OBB packaging.

## What is ready

- The manifest contains 20 English and 20 Spanish clubs in the order found in
  Football Life `CompetitionEntry.bin`.
- Thirty-nine IDs already exist in PES21 Mobile. The generator patches only
  the 70-byte English-name field and the two four-byte short-code fields in
  those rows.
- The Team.bin record count stays at 736 and every unrelated row must remain
  byte-identical.
- Sunderland AFC (`396`) is retained as the English league's twentieth target,
  but its team record and selector integration remain pending because that ID
  is absent from the tested PES21 Mobile Team.bin.
- Football Life supplies four real-uniform descriptors and matching base kit
  textures for every target team. The generator records the winning source
  member using update precedence `c > b > a > dt34`.

The source manifest is
`data/eng_spa_license_overrides.json`; the isolated builder is
`tools/build_eng_spa_license_pack.py`.

## Generated output

Running the builder creates ignored local output under
`local-debug/eng-spa-license-pack`:

- `Team.bin`: a WESYS-encoded PES21 table with official names/codes for the 39
  existing targets;
- `selector-name-overrides.json`: the official selector labels for later
  catalog integration;
- `kit-source-manifest.json`: descriptor and PC FTEX provenance for all 160 kit
  definitions;
- `validation-report.json`: source hashes, changed-byte ranges, counts, and
  safety warnings;
- `README.md`: a generated target/status table for the local pack.

No generated file is currently consumed by the runtime or embedded in the
NRO. This keeps the work rebase-safe while the other runtime lanes are active.

## Why kits remain conversion-pending

Football Life's kit textures are PC FTEX files. PES21 Mobile resolves cooked
UE4 texture assets, so copying FTEX bytes into a mobile PAK/CPK would not be a
valid port. The audited mobile database also exposes two additional limits:

- only Manchester United (`100`), Arsenal (`101`), and FC Barcelona (`108`)
  have any native 120-byte real-uniform descriptors among these targets;
- the other clubs use 96-byte generic descriptors or missing members, and
  Sunderland has no native descriptor members at all.

The current CPK repacker can replace an existing member with a different-sized
payload, but it cannot add a new member name. A 120-byte Football Life
descriptor must therefore not be written over a 96-byte generic member until
the mobile loader policy is proven. Sunderland additionally needs a safe
member-addition strategy.

The next kit phase should:

1. decode the winning FTEX source to lossless RGBA/material channels;
2. identify and extract a real PES21 Mobile uniform cooked-texture template;
3. encode one detachable canary team without overwriting stable release files;
4. verify home, away, goalkeeper, number/name, thumbnail, and match rendering;
5. only then scale the conversion and integrate descriptor/texture packaging.

## Safety gates

- Never replace the complete Football Life Team.bin; it has 743 records and is
  not the tested PES21 Mobile table.
- Always apply the name patch to the current release-base Team.bin so unrelated
  player/team experiments are preserved.
- Keep Sunderland `pending` until team, roster, tactics, badge, selector, and
  uniform resources are solved as one coordinated addition.
- Keep PC FTEX assets out of the public tree and out of runtime packages until
  a compatible mobile conversion has been validated.
- Do not run the NRO build from this lane; hand the data-only outputs to the
  integration agent after its runtime checkpoint is stable.

## Usage

```powershell
python tools/build_eng_spa_license_pack.py --football-life-root "<football-life-root>"
python tools/build_eng_spa_license_pack.py --football-life-root "<football-life-root>" --check
python -m pytest -q tests/test_eng_spa_license_pack.py
```

For the optional local integration assertions, set
`PESNX_FOOTBALL_LIFE_ROOT` before running the focused test. The repository does
not store a machine-specific Football Life path.

To rebase onto a newer already-patched Team.bin, pass it explicitly with
`--pes21-team`. Source-hash drift is rejected by default; use
`--allow-source-drift` only after reviewing the changed table revision and the
generated byte-preservation report.
