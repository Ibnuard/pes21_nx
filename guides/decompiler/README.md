# Decompiler references

Raw symbols, disassembly excerpts, and temporary reverse-engineering notes are
stored locally under `raw/`. That directory is intentionally ignored because
it can contain proprietary output and very large generated files.

Use the raw files as evidence while investigating, then record durable offsets,
ABI conclusions, validation steps, and limitations in a concise document under
`docs/` or a maintained guide here. Do not commit full library dumps, extracted
assets, or bulk decompiler output.
