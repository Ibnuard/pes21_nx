# FNX Ronaldo launcher icon v1

Created with the built-in image-generation tool, using these existing project references:

- `art/main_menu/portrait-credits-source.png`: Ronaldo portrait.
- `art/main_menu/brand-logo-runtime.png`: typography and palette.

Master: `fnx-ronaldo-v1.png`. Launcher export: `fnx-ronaldo-v1-256.jpg`.
The root `icon.jpg` is the Makefile input. The runtime preparer preserves the
release icon by default; `--apk-icon` explicitly selects the legacy APK artwork.
The image does not change any runtime executable/validation settings.

Primary request: create one beautifully restrained modern FNX football launcher icon using this existing Ronaldo portrait. Preserve Ronaldo's exact face, smiling side profile, hair, yellow jersey, blue armband and raised-arm celebration pose; crop the provided photo to head and upper shoulders/raised forearm, do not invent a different portrait. Face should be large and unmistakable in upper two-thirds. Use flat near-black midnight navy background with ample clean breathing room; original photographic skin tones, crisp edges.
Bottom portion: prominent compact geometric italic monogram with EXACT text "FNX", F and N white, X acid yellow #EFFF00, one tiny magenta #FF2670 diagonal accent inspired by supplied NX logo. Clean sporty wide letterforms like the supplied wordmark, three letters clearly readable. Balance portrait and lettering so neither obscures the face. Subtle dark fade behind lettering for contrast, no excessive effects.
Full bleed square 1024x1024 opaque artwork with square corners. Keep the face and all lettering comfortably inside an 8 percent safe margin. Simple, premium, modern; only the portrait and FNX mark. No extra slogans, no small year text, no border, no rounded frame, no UI, no console mockup, no ball, no stadium, no lightning, no neon glow, no checkerboard. Do not add any text other than FNX (existing jersey markings may remain if in crop).
